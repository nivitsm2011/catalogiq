| 2026-10-04 | Listing quality score = Bayesian-shrunk rating rescaled to 0-1: `shrunk = v/(v+50)*R + 50/(v+50)*C`, `score = (shrunk-1)/4`. A first threshold of 0.80 gave 47.5% exemplars (too lenient); 0.85 gives 191 of 800 (23.9%). |
| 2026-10-04 | EDA compares "performing" listings using score and volume only, not completeness | Compare exemplars | Exemplars require >= 3 bullets by definition, so comparing bullet counts would be circular. |
